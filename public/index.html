Basics
  • Double click empty space to create a note.
  • Double click inside a group to create a note in that group.
  • Drag notes to move them, drag onto a note to connect.
  • Shift + drag to box select groups and top-level notes.

Tips
  • Collapse groups to focus; connections will attach to the collapsed indicator.
  • Use the note inspector to group selections or fit notes to content.
  • Right click the canvas for quick actions.
AI Brainstorm

Describe what you want to brainstorm and the AI will add a set of notes and connections to the canvas.

Clear Board

This will remove all notes, groups, and connections from the current board. This action cannot be undone.
